# CSE221 (Summer 2024) – Algorithms (BRAC University)

Lab assignments from CSE221, BRAC University's algorithms course,
implemented in Python. Covers sorting, two-pointer and greedy techniques,
divide and conquer, graph traversal, topological sorting, and shortest paths.

Each lab folder contains a notebook plus the `inputN.txt` files it reads
and the `outputN.txt` files it produced.

## Labs

| Lab | Topic | What's inside |
|-----|-------|---------------|
| [01](Lab01) | Elementary sorting | Bubble, insertion, and selection sort; sorting records by multiple keys |
| [02](Lab02) | Two pointer & greedy | Two-sum, merging sorted lists, interval scheduling |
| [03](Lab03) | Divide & conquer | Merge sort, divide-and-conquer maximum, inversion counting |
| [04](Lab04) | Graph traversal | DFS traversal, plus class notes on BFS, shortest paths, components, and DSU |
| [05](Lab05) | Topological sorting | DFS-based and BFS (Kahn's) topological sort, lexicographically smallest order |
| [06](Lab06) | Shortest paths | Dijkstra's algorithm with a priority queue |

## How to run
Each notebook reads its input files from its own folder.

- **Jupyter:** open the notebook from inside its lab folder and run all cells.
- **Google Colab:** open the notebook, upload that lab's `input*.txt` files
  using the Files panel, then run all cells.

## Tools
Python 3 · Jupyter / Google Colab
